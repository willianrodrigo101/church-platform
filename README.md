# Church Platform

Plataforma modular multi-igreja para gestão pastoral.

## Stack

| Camada | Tecnologia |
|---|---|
| Backend | Python 3.13 + FastAPI |
| Banco | PostgreSQL 18 + SQLAlchemy async (psycopg) |
| Migrations | Alembic |
| Frontend | HTML + CSS + JavaScript puro |
| Gráficos | Chart.js (CDN) |
| Docs API | Swagger UI (`/docs`) |
| Auth | JWT + bcrypt |
